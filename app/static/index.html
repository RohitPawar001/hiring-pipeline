📖 How to Use Mini Hiring Pipeline

1. Kanban Board & Strict State Machine

Candidates advance linearly: Applied → Screening → Interview → Offer → Hired. Candidates can be Rejected from any active stage. Final stages (Hired / Rejected) are permanently locked.

2. Moving Candidates & Audit Notes

Click Next → [Stage] or Reject on any candidate card. A modal will prompt for an optional Audit Note (e.g., "Passed tech round"), which is permanently appended to the database audit trail.

3. Candidate Detail & Audit History

Click anywhere on a card to open the Detail Drawer on the right. You will see total days in the active stage and the complete chronological event log with timestamps.

4. Smart Natural Language Search

Type queries into the top search bar. Supports fuzzy typo tolerance via Damerau-Levenshtein ("sharam" → "Rohit Sharma"), stage inclusion/exclusion ("in Screening", "except rejected"), duration filters ("stuck in interview", "more than 3 days"), and historical transitions ("reached offer but not hired", "moved to interview since monday").
